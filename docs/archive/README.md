# Historical Schema Designs

These documents preserve the comprehensive design that preceded the reduced MVP.
They contain deferred fields, record types and policies that are not current
implementation requirements. Start with the [current documentation](../README.md).

- [Schema plan](schema-plan.md): original inventory, principles and conventions.
- [Field design](schema-field-design.md): detailed shapes for the comprehensive family.
- [Consistency review](schema-consistency-review.md): resolved design conflicts and rationale.

The [schema registry](../../schemas/README.md) describes the current record scope.
Current schema semantics belong to the versioned JSON schemas and the
usage and compatibility guides, not this archive.
